# Biodome
My programming for a first-person game in Godot

This is so far the code I have created. This is a small part of a much bigger project. 

This code will allow any object to be an interactable object. 
The player character needs to have the interaction controller and the pickup controller attached, to send signals to the items that are being interacted. 

An interactable item needs to have physics pickup as a component to be able to be pickupable. 

This is a small part of a bigger system that is being done. So far the system allows you to pick up items, hold them while walking and looking around, and drop them. 
It is also possible to press buttons, and the items connected to the button will execute the action attached to themselfs.
